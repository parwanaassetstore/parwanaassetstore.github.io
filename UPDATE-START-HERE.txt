STEP 1: parwana-store-v3-update-only.zip download kar ke Extract All karo.
STEP 2: Extracted folder "Parwana-Store-V3-Update" kholo.
STEP 3: GitHub repository => Code => Add file => Upload files.
STEP 4: Extracted folder ke ANDAR ka content upload karo (src, public, tools, scripts...).
STEP 5: Commit changes dabao. Actions ka GREEN CHECK aane do.
STEP 6: Site kholo, Ctrl + Shift + R dabao.

ZAROORI BAAT:
- Update-only ZIP mein public/data/assets.json NAHI HAI. Purane assets safe rahenge.
- .github dobara upload NAHI karna.
- Apne real images GitHub par upload karne ki zaroorat nahi.

NAYA ASSET ADD KARNE KA TAREEQA:
1. Parwana-Asset-Manager.html ko computer par double click karke kholo.
2. GitHub se apni LATEST public/data/assets.json download kar ke Import assets.json karo.
3. + New asset dabao, category choose karo.
4. Copyrighted category? YES ya NO choose karo.
5. Main image ka Google Drive FILE share link paste karo.
6. Extra images: ek link per line paste karo.
7. YouTube video link paste karo (optional).
8. ZIP/Unitypackage ka alag Google Drive public link paste karo.
9. Save record => Export assets.json.
10. Export wali assets.json ko GitHub ke public/data/assets.json par replace karke Commit changes karo.

Har image ko Drive mein Anyone with the link -> Viewer karna hoga.
NOTE: Google Drive ka direct thumbnail display kabhi kabhi block ho sakta hai.
Agar image show na ho to public sharing check karo aur browser Incognito mein test karo.
